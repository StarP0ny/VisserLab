# VisserLab

Регистратор опытов. Приборы подключаются как плагины, запись идёт в папку опыта, журнал ведётся рядом с данными, управлять можно с ПК или с телефона.

Готовы **сборщик** (приборы, запись, предзапись, журнал, тревоги) и **веб-интерфейс**: окно 0, выбор и настройка приборов, панель опыта с графиками, кадром тепловизора, журналом и раскладкой для телефона. Одобренный макет: [docs/mockup.html](docs/mockup.html).

## Установка

```
pip install -e ".[dev]"
```

## Запуск

Два окна консоли:

```
python -m visserlab collect          # сборщик: держит приборы и пишет опыты; Ctrl-C — стоп с сохранением
python -m visserlab web              # веб: http://127.0.0.1:8080/
```

Для телефона запустите `python -m visserlab web --host 0.0.0.0`. Веб напечатает ссылку с токеном; без токена с другого устройства не пустит. Если сборщик не запущен, веб это покажет, но сам его не запустит.

Без стенда можно работать на симуляторах: шаблон `sim` поднимает Pt100, тепловизор, МК-шлюз с SCD41 / SHT45 / SDP810, шприц и вычисляемую влажность, время в них ускорено в 10 раз.

Консоль вместо веба:

```
python -m visserlab devices                                  # кто из приборов отвечает
python -m visserlab ctl prepare name=dry03 template=visser_patron
python -m visserlab ctl start | note текст | pause | stop | watch
python -m visserlab record --template sim                    # без сборщика: запись прямо из консоли
```

## Устройство

```
config/devices.yaml        приборы стенда: драйвер, настройки, подписи каналов, дети шлюзов
config/templates/*.yaml    шаблоны опытов: приборы, настройки, правила тревог
src/visserlab/core/        ядро: контракт драйвера, сборщик, запись, буферы, тревоги, TCP-сервер
src/visserlab/drivers/     pta8d08 (Pt100), manual, calc, sim
src/visserlab/web/         мост WebSocket ⇄ сборщик и статика интерфейса
docs/COLLECTOR.md          протокол, состояния, формат опыта на диске
tests/                     ядро и веб на симуляторах: python -m pytest
```

## Приборы

| Прибор | Подключение | Статус |
|---|---|---|
| PTA8D08, 8 × Pt100 | Modbus RTU, RS485 | работает. Регистры 0–7 — °C×10, 32–39 — Ом×10 |
| Victor 328B, тепловизор | USB UVC | не проверено, отдаёт ли он UVC; есть симулятор |
| SCD41, SHT45, SDP810, O₂ | через МК-шлюз | протокол шлюза ещё не продуман; есть симуляторы |
| Шприц-проба, весы | ручной ввод | работает |

## Решения по интерфейсу

- Окно 0: новый опыт или анализ. Если опыт идёт, по центру висит плашка с переходом к нему. Опыт всегда один.
- Шаг 1: выбор приборов, плитками или списком. Автопоиск проверяет каждый прибор на параметрах драйвера по умолчанию, недоступные скрыты.
- Шаг 1.1: настройки. Форма строится из схемы драйвера, шаг можно пропустить.
- Подготовка → запись ⇄ пауза → стоп. Стоп возможен только из паузы, на паузе запись продолжается.
- Значок состояния: зелёный — норма, жёлтый — нужно внимание, красный — ошибка.
- График прибора перетаскивается на поле. Брошенный на панель, он накладывается на неё, но не больше двух единиц измерения на панель. С Alt (на телефоне — долгое нажатие) переносится прибор целиком, по панели на единицу измерения.
- Ширина панели: 1 → 2 → вся строка. Раскладка запоминается в браузере отдельно для каждого опыта.
- Журнал: время заметки берётся по первому нажатию клавиши. Изменения настроек записываются как «было → стало».
- Точки замера на кадре тепловизора становятся каналами.
- Тексты короткие, пояснения во всплывающих подсказках.
