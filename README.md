# VisserLab

Регистратор опытов. Приборы подключаются как плагины, запись идёт в папку опыта, журнал ведётся рядом с данными, управлять можно с ПК или с телефона.

Сейчас готов **сборщик**: состояния опыта, запись, предзапись, журнал, тревоги и сетевой протокол для клиентов. Управлять им пока можно из консоли. Веб-интерфейс существует только как макет: [docs/mockup.html](docs/mockup.html).

## Запуск

```
pip install -r requirements.txt

python -m visserlab devices                     # приборы из конфига: отвечают ли
python -m visserlab collect                     # сборщик; Ctrl-C — остановить

python -m visserlab ctl prepare name=dry03 template=visser_patron
python -m visserlab ctl start
python -m visserlab ctl note пошло дыхание
python -m visserlab ctl action syringe add value=0,43
python -m visserlab ctl pause
python -m visserlab ctl stop
python -m visserlab ctl watch                   # поток событий

python -m visserlab record --template sim       # без сборщика: запись из консоли
```

В `record`: Enter ставит метку, текст + Enter — заметку, `p` — пауза, `q` — стоп.

Без стенда можно работать на симуляторах: `template=sim` поднимает Pt100, тепловизор, МК-шлюз с SCD41 / SHT45 / SDP810, шприц и вычисляемую влажность, время в них ускорено в 10 раз.

## Устройство

```
config/devices.yaml       приборы стенда: драйвер, настройки, подписи каналов, дети шлюзов
config/templates/*.yaml   шаблоны опытов: приборы, настройки, правила тревог
visserlab/core/           ядро: драйвер-контракт, сборщик, запись, буферы, тревоги, сервер
visserlab/drivers/        pta8d08 (Pt100), manual, calc, sim
docs/COLLECTOR.md         протокол, состояния, формат опыта на диске
tests/                    ядро на симуляторах: python -m pytest tests
```

## Приборы

| Прибор | Подключение | Статус |
|---|---|---|
| PTA8D08, 8 × Pt100 | Modbus RTU, RS485 | работает. Регистры 0–7 — °C×10, 32–39 — Ом×10 |
| Victor 328B, тепловизор | USB UVC | не проверено, отдаёт ли он UVC |
| SCD41, SHT45, SDP810, O₂ | через МК-шлюз | протокол шлюза ещё не продуман; пока есть симуляторы |
| Шприц-проба, весы | ручной ввод | работает |

## Решения по интерфейсу

- Окно 0: новый опыт или анализ. Если опыт идёт, по центру висит плашка с кнопкой перехода к нему. Опыт всегда один.
- Шаг 1: выбор приборов, плитками или списком. Автопоиск проверяет каждый прибор на параметрах драйвера по умолчанию. Недоступные скрыты.
- Шаг 1.1: настройки. Форма генерируется из схемы драйвера, шаг можно пропустить.
- Подготовка → запись ⇄ пауза → стоп. Стоп возможен только из паузы, на паузе запись продолжается.
- Значок состояния: зелёный — норма, жёлтый — нужно внимание, красный — ошибка.
- Графики перетаскиваются на поле. Брошенный на панель график накладывается на неё, но не больше двух единиц измерения на панель. С Alt (на телефоне — долгое нажатие) переносится прибор целиком, по панели на единицу измерения.
- Ширина панели: 1 → 2 → вся строка. Панель можно вынести в отдельное окно браузера.
- Журнал: время заметки берётся по первому нажатию клавиши. Изменения настроек записываются как «было → стало».
- Точки замера на кадре тепловизора становятся каналами.
- Сборщик запускает человек. Веб только сообщает, что сборщика нет.
- Тексты короткие, пояснения во всплывающих подсказках.
